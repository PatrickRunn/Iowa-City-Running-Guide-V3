# Iowa City Running Guide

A four-page fictional educational website for MKTG:4400 at the University of Iowa.

## Pages
- index.html: Home
- routes.html: Running routes
- beginners.html: Beginner's guide
- resources.html: Running resources

## Publishing
1. Upload all site files to the root of the `main` branch.
2. In GitHub, open Settings > Pages. Under **Build and deployment**, choose **Deploy from a branch**, `main`, and `/ (root)`, then Save.
3. The expected site URL is `https://YOUR_GITHUB_USERNAME.github.io/iowa-city-running-guide-v2/` (substitute your username).
4. Replace `YOUR_GITHUB_USERNAME` in `robots.txt` and `sitemap.xml` with your real username. Commit those changes.
5. Check that each page works, including on a phone, and that the site loads in a private window.
6. Add and verify the site in Google Search Console, submit `sitemap.xml`, and record baseline measurements.

Note: At least four commits on **different dates** with explanatory commit messages are required by the assignment. Creating four commits in a single day does not satisfy this rule. Do not falsify dates.
