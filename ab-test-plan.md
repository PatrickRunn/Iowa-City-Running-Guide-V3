1. Page and change
I will test one element on the homepage: the call-to-action button in the “Explore running routes” section. Version A uses “See Iowa City running routes.” Version B will use “Find Your Perfect Running Route.” Both buttons link to the same routes page. No other page content or design will change.

2. Hypothesis
I predict Version B will receive more “YES” responses to the question of whether a visitor would click the button. Its wording emphasizes a personalized benefit, while Version A simply describes the destination.

3. AI visitors and exact prompt
I will use GPT-6 with the same selected configuration and settings for every trial, in a new conversation without prior-trial memory. The persona is a University of Iowa student who lives in Iowa City, runs recreationally, and wants routes near campus.

"You are a University of Iowa student living in Iowa City. You enjoy recreational running and want to find new running routes near campus. You have discovered the following website homepage. Read the page carefully and decide whether you would click the button in the 'Explore running routes' section. Answer YES or NO, followed by one sentence explaining your decision. Base your answer only on the webpage provided.

WEBPAGE:
[COMPLETE ASSIGNED HOMEPAGE TEXT]”

4. Random assignment and measurement
Before starting, I will generate and save a shuffled trial schedule with 50 A assignments and 50 B assignments. I will follow that order. The primary outcome is whether each AI visitor says it would click: YES = 1 and NO = 0. I will save the exact response and reasoning for every trial.

5. Sample size and timing
I will run 100 independent trials, 50 for each version, launch by November 17, and finish by November 24, 2026. I will not stop early, remove inconvenient responses, or revise the hypothesis after seeing results.

6. Analysis and decision rule
I will compare the YES percentages for A and B, calculate B minus A in percentage points, and use a two-proportion test (or an exact test if appropriate) at a 0.05 significance level. The hypothesis receives statistical support only if B has a higher YES rate and p < 0.05. I will report nonsignificant results as well. AI-stated intentions are not actual human clicks.

7. Implementation and records
I will keep A as the original page and publish B separately with a noindex tag, excluding B from the sitemap. I will save the plan commit link, both page addresses and screenshots, prompts, model/version and settings, batch dates, all outputs, a CSV with one row per trial, statistical calculations, and a dated issue log. Any post-launch changes will be disclosed.
